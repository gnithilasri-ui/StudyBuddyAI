\# StudyBuddy AI 🎓



An AI-powered personalized learning web application built with Python, Streamlit, and Google Gemini.



\## 🚀 Features



\- 📚 AI-generated study material

\- 🧠 AI-generated quizzes

\- 📊 Learning progress tracking

\- 🎯 Difficulty-based learning

\- 📝 Quick summaries and key takeaways

\- 🌍 Real-world examples

\- 📈 Quiz score and performance tracking

\- 💾 Downloadable study notes

\- 📱 Responsive web interface



\## 🛠️ Tech Stack



\- Python

\- Streamlit

\- Google Gemini API

\- Google GenAI SDK

\- python-dotenv



\## ⚙️ How It Works



1\. Select a subject.

2\. Choose the difficulty level.

3\. Enter a topic.

4\. Study the AI-generated learning material.

5\. Attempt the generated quiz.

6\. View scores and learning progress.
